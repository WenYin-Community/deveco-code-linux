## SDK 生成文件：建议填写的屏蔽理由

**点位：** `packages/sdk/js/src/v2/gen/types.gen.ts`，超大源文件，9450 → 9473。

> 该文件是 SDK 构建脚本根据源 Schema 自动生成的类型产物，基线已超过 2000 行阈值。本次增加的类型和字段用于表达输出截断、空响应及原始结束原因，必须与服务端 Schema 保持一致。手工压缩或拆分生成结果会在重新生成时被覆盖，文件组织应由生成工具统一管理。本次申请仅屏蔽该生成文件的“超大源文件”告警，保留类型检查及其他规则；生成器拆分作为独立治理事项处理。

这是生成产物的规则适用性豁免，不是误报，也不取消 SDK 类型变更。本轮整改没有改动该文件或生成脚本。
