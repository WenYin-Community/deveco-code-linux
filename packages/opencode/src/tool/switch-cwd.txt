Switch the session project context directory for Harmony project actions.

Use this tool before running `devecocli build` or `devecocli run` for another project.
These commands only work correctly when the context directory is a valid project path.
If the current context directory is already the ArkTS project root, do not switch again.

**After a successful `devecocli create`:** the session directory is
automatically set to the generated project root. You do NOT need to call `switch_cwd`
after a successful scaffold — proceed directly to reading templates and writing code.
Use this tool only as a fallback (manual directory change, or if auto-switch did not trigger).

Accepts absolute paths and relative paths (resolved from the current workspace directory).

For project-creation requests (新建/创建/scaffold), load the `deveco-cli` skill and run `devecocli create`. If the target already exists, the command emits `PROJECT_EXISTS` (exit 2) — use `question` to let the user choose overwrite/rename/cancel.
