Switch the session project context directory for Harmony project actions.

Use this tool before running `build_project` or `start_app`.
These tools only work correctly when the context directory is a valid project path.
If the current context directory is already the ArkTS project root, do not switch again.

**After `devecocli create`:** use the `Project root` reported by the CLI as the working
directory for subsequent project commands. Use this tool only when the session context
must be changed explicitly.

Accepts absolute paths and relative paths (resolved from the current workspace directory).

For project-creation requests (新建/创建/scaffold), load the `deveco-cli` skill and run `devecocli create` instead of using this tool to jump to an existing directory. If the CLI reports a target-directory conflict, ask the user to choose a different path or cancel; never delete or overwrite the directory without explicit approval.
