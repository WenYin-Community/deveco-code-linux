# DevEco Code licensing policy

DevEco Code is distributed under the [Apache License 2.0](LICENSE). This policy
takes effect with the commit that introduces the repository-wide Apache-2.0
license. It applies to the project code throughout the repository, including
existing project files and new original contributions after that commit.

Project code previously distributed under MIT, including code derived from
OpenCode, is sublicensed under Apache-2.0 in DevEco Code distributions starting
with that commit. The upstream copyright and [MIT license notice](LICENSES/MIT.txt)
are preserved. Recipients of earlier MIT releases can continue to use those
releases under MIT. This sublicense grants no patent rights on behalf of
upstream MIT contributors.

Third-party material retains its applicable licenses and attribution.
Preserve existing copyright, license, and attribution notices when editing
or importing code. See [NOTICE](NOTICE) for attribution. Contributors must
have the right to submit their contributions under Apache-2.0.

New original project files are covered by this policy and do not require an
individual license header. An optional header can use
`SPDX-License-Identifier: Apache-2.0`.

Distribute `LICENSE`, `LICENSING.md`, `NOTICE`, and `LICENSES/MIT.txt`
with DevEco Code releases, along with applicable third-party notices.
